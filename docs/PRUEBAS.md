# Pruebas manuales del sistema

## Objetivo
Verificar que las funcionalidades principales del sistema funcionen correctamente mediante pruebas manuales.

## Lista de verificación

| No. | Funcionalidad | Acción realizada | Resultado esperado | Estado |
|---|---|---|---|---|
| 1 | Crear usuario | Se registró un usuario con nombre, correo y contraseña | El usuario se guarda y aparece en la tabla | Aprobado |
| 2 | Consultar usuarios | Se revisó la tabla de usuarios registrados | Los usuarios aparecen correctamente en el listado | Aprobado |
| 3 | Editar usuario | Se modificó el nombre y correo de un usuario | Los datos se actualizan correctamente | Aprobado |
| 4 | Eliminar usuario | Se eliminó un usuario desde la interfaz | El usuario desaparece del listado | Aprobado |
| 5 | Login | Se ingresó correo y contraseña de un usuario registrado | El sistema inicia sesión correctamente | Aprobado |
| 6 | Logout | Se presionó el botón para cerrar sesión | El sistema cierra la sesión correctamente | Aprobado |

## Resultados
Las pruebas manuales se realizaron desde la interfaz web del sistema. Las funcionalidades principales respondieron correctamente y se documentaron mediante capturas de pantalla para el informe final.

## Observaciones
Durante las pruebas se utilizaron datos temporales. Antes de guardar los cambios finales, el archivo de usuarios fue limpiado para evitar subir información innecesaria al repositorio.
