# Proyecto-Garcia-Gallardo

## Nombre del proyecto
Gestor de infraestructura Web para desarrollo.

## Objetivo
Desarrollar una aplicación web mínima aplicando el ciclo de vida del desarrollo de software, trabajo colaborativo en GitHub, control de versiones, Issues, Pull Requests y evidencias de pruebas.

## Tecnologías utilizadas
- Node.js
- Express
- HTML simple
- CSS
- JavaScript
- GitHub Projects
- GitHub Issues
- Pull Requests

## Arquitectura general
El proyecto cuenta con una estructura sencilla:

- server.js: servidor backend con Node.js y Express.
- public: archivos del frontend.
- data: almacenamiento temporal en archivo JSON.
- docs: documentación y evidencias.
- screenshots: carpeta para capturas de evidencia.

## Cómo ejecutar el proyecto

1. Instalar dependencias:

npm install

2. Ejecutar servidor:

npm run dev

3. Abrir en el navegador:

http://localhost:3000

## Flujo Git utilizado
1. Crear Issue.
2. Crear rama para la funcionalidad.
3. Realizar cambios.
4. Hacer commit descriptivo.
5. Crear Pull Request.
6. Revisar y aprobar el Pull Request.
7. Fusionar cambios a main.
8. Cerrar Issue.
